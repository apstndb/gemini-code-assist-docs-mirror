NAME

gcloud gemini code-repository-indexes - manage Code Repository Index resources

SYNOPSIS

`gcloud gemini code-repository-indexes` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/code-repository-indexes#GROUP) \| [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/code-repository-indexes#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/code-repository-indexes#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Manage Code Repository Index resources.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

GROUPS

`GROUP` is one of the following:

[`repository-groups`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/code-repository-indexes/repository-groups)  
Manage Repository Group resources.

COMMANDS

`COMMAND` is one of the following:

[`create`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/code-repository-indexes/create)  
Create a code repository index instance.

[`delete`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/code-repository-indexes/delete)  
Delete a code repository index instance.

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/code-repository-indexes/describe)  
Get details of a code repository index instance.

[`list`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/code-repository-indexes/list)  
List all code repository index instances in a specified project and location.

[`update`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/code-repository-indexes/update)  
Update the configuration of a code repository index instance.
