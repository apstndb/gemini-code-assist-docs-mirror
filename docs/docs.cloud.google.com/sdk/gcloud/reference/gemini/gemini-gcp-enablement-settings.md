NAME

gcloud gemini gemini-gcp-enablement-settings - manage Gemini Gcp Enablement Setting resources

SYNOPSIS

`gcloud gemini gemini-gcp-enablement-settings` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/gemini-gcp-enablement-settings#GROUP) \| [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/gemini-gcp-enablement-settings#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/gemini-gcp-enablement-settings#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Manage Gemini Gcp Enablement Setting resources.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

`GROUP` is one of the following:

[`setting-bindings`](https://docs.cloud.google.com/sdk/gcloud/reference/gemini/gemini-gcp-enablement-settings/setting-bindings)
