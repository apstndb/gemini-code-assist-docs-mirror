NAME

gcloud gemini operations - manage Operation resources

SYNOPSIS

`gcloud gemini operations` `  COMMAND  ` \[ `  GCLOUD_WIDE_FLAG …  ` \]

DESCRIPTION

Manage Operation resources.

GCLOUD WIDE FLAGS

These flags are available to all commands: `  --help  ` .

Run ` $ gcloud help  ` for details.

COMMANDS

`  COMMAND  ` is one of the following:

  - `  cancel  `  
    Cancel operations.
  - `  delete  `  
    Delete operations.
  - `  describe  `  
    Describe operations.
  - `  list  `  
    List operations.
  - `  wait  `  
    Wait operations.
