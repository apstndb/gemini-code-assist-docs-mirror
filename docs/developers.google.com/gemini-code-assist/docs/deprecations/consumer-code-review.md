The [consumer version of Gemini Code Assist on GitHub](https://docs.cloud.google.com/gemini/docs/code-review/review-repo-code#versions) is being sunset. The enterprise version of Gemini Code Assist on GitHub is not affected by these changes.

  - Starting **June 18, 2026** , the consumer version is deprecated, and you can't complete installations of the consumer version of the app.

  - Starting **July 17, 2026** , the consumer version is shut down, and all code review activities performed by the app end.

For instructions on how to uninstall the Gemini Code Assist app from GitHub, see [Deleting a GitHub app](https://docs.github.com/en/apps/maintaining-github-apps/deleting-a-github-app) .
