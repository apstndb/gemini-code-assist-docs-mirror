Gemini Code Assist offers AI-powered assistance to help your development team build, deploy, and operate applications throughout the software development lifecycle. Gemini Code Assist is available in two editions, which are managed through Google Cloud:

  - [Gemini Code Assist Standard](https://docs.cloud.google.com/gemini/docs/codeassist/overview#supported-features)

  - [Gemini Code Assist Enterprise](https://docs.cloud.google.com/gemini/docs/codeassist/overview#supported-features)

Documentation for Gemini Code Assist, including setup instructions and how-to guides, can be found in the [Google Cloud documentation for Gemini Code Assist](https://docs.cloud.google.com/gemini/docs/codeassist/overview) .
