The following table lists Gemini Code Assist feature deprecations and their shutdown schedule:

| Feature                                                                                                                    | Deprecated date   | Shutdown date    | More information                                                                                                                                                                                                                                                                                                                |
|----------------------------------------------------------------------------------------------------------------------------|-------------------|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Gemini Code Assist renewal of monthly Standard and Enterprise subscriptions                                                | December 31, 2027 |                  | After December 31, 2027, you can no longer renew monthly Standard or Enterprise subscriptions for Gemini Code Assist. For more information, see the [deprecation page](https://docs.cloud.google.com/gemini/docs/codeassist/sunset) .                                                                                           |
| Gemini Code Assist renewal of annual Standard and Enterprise subscriptions                                                 | January 31, 2027  |                  | After January 31, 2027, you can no longer renew annual Standard or Enterprise subscriptions for Gemini Code Assist. For more information, see the [deprecation page](https://docs.cloud.google.com/gemini/docs/codeassist/sunset) .                                                                                             |
| Gemini Code Assist additional licenses for Standard and Enterprise subscriptions                                           | January 31, 2027  |                  | After January 31, 2027, you can no longer purchase additional licenses for your Gemini Code Assist Standard or Enterprise subscriptions. For more information, see the [deprecation page](https://docs.cloud.google.com/gemini/docs/codeassist/sunset) .                                                                        |
| Gemini Code Assist new Standard and Enterprise subscriptions                                                               | October 9, 2026   |                  | After October 9, 2026, you can no longer purchase new Gemini Code Assist Standard or Enterprise subscriptions. For more information, see the [deprecation page](https://docs.cloud.google.com/gemini/docs/codeassist/sunset) .                                                                                                  |
| Consumer version of [Gemini Code Assist on GitHub](https://docs.cloud.google.com/gemini/docs/code-review/review-repo-code) | June 18, 2026     | July 17, 2026    | [Consumer version sunset](https://developers.google.com/gemini-code-assist/docs/deprecations/consumer-code-review)                                                                                                                                                                                                              |
| Gemini Code Assist consumer accounts                                                                                       | May 18, 2026      | Jun 18, 2026     | After June 18, 2026, Gemini Code Assist IDE extensions and Gemini CLI will stop serving requests for Google AI Pro and Ultra, as well as for Gemini Code Assist for individuals. For more information, see the [deprecation page](https://developers.google.com/gemini-code-assist/docs/deprecations/code-assist-individuals) . |
| Gemini Code Assist tools                                                                                                   | October 2, 2025   | October 14, 2025 | After October 14, 2025, calling Gemini Code Assist tools using the `@` operator with the tool name won't work. Tools are replaced by [agent mode](https://developers.google.com/gemini-code-assist/docs/agent-mode) .                                                                                                           |
