The following table lists Gemini Code Assist feature deprecations and their shutdown schedule:

| Feature                                                                                                                    | Deprecated date | Shutdown date    | More information                                                                                                                                                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------- | --------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Consumer version of [Gemini Code Assist on GitHub](https://docs.cloud.google.com/gemini/docs/code-review/review-repo-code) | June 18, 2026   | July 17, 2026    | [Consumer version sunset](https://developers.google.com/gemini-code-assist/docs/deprecations/consumer-code-review)                                                                                                                                                                                                              |
| Gemini Code Assist consumer accounts                                                                                       | May 18, 2026    | Jun 18, 2026     | After June 18, 2026, Gemini Code Assist IDE extensions and Gemini CLI will stop serving requests for Google AI Pro and Ultra, as well as for Gemini Code Assist for individuals. For more information, see the [deprecation page](https://developers.google.com/gemini-code-assist/docs/deprecations/code-assist-individuals) . |
| Gemini Code Assist tools                                                                                                   | October 2, 2025 | October 14, 2025 | After October 14, 2025, calling Gemini Code Assist tools using the `@` operator with the tool name won't work. Tools are replaced by [agent mode](https://developers.google.com/gemini-code-assist/docs/agent-mode) .                                                                                                           |
