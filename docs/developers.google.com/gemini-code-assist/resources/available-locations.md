The following is a list of locations where Google enables [Gemini Code Assist for individuals](https://developers.google.com/gemini-code-assist/docs/overview) , the free version of Gemini Code Assist, which includes access to Gemini CLI, Antigravity, and Gemini Code Assist plugins in VS Code and JetBrains.

The page also shows the locations where you can purchase a [Google AI Pro or Google AI Ultra subscription](https://gemini.google/subscriptions/) , which provides access to the same features as Gemini Code Assist for individuals and offers [higher daily model request limits](https://developers.google.com/gemini-code-assist/resources/quotas) :
